# Knocky

Сервис онлайн-приглашений на праздники по ссылке. Прототип сайта живёт на https://knocky.ru (GitHub Pages), закрыт паролем.

## Как устроен репозиторий

- `index.html` — весь сайт, зашифрованный (AES-GCM). Исходник в открытом виде здесь не хранится: репозиторий публичный.
- `tools/decrypt_site.py` — достать исходник: `python3 tools/decrypt_site.py index.html konvert.html ПАРОЛЬ`.
- `tools/encrypt_site.py` — зашифровать обратно: `python3 tools/encrypt_site.py konvert.html index.html ПАРОЛЬ1 ПАРОЛЬ2`. Паролей два (владелец и второй администратор), передавать оба, иначе один из них перестанет работать. Пароли знает только владелец, в репозиторий и документы их не пишем.
- `server/` — рабочий сервер (Timeweb Cloud, `knocky-app`, Москва). Сервер раз в минуту забирает ветку `main` и запускает `server/deploy.sh`. SSH не используется. `server/cloud-init.yaml` — скрипт, с которым сервер создан. Статус сервера: https://app.knocky.ru (после записи A `app` в Cloudflare).
- `CNAME` — домен knocky.ru для GitHub Pages.

## Правила

- Сайт — один файл `konvert.html`, без сборки. После правки: зашифровать, закоммитить `index.html`, запушить.
- Фирменные цвета: красный #C62828, тёмный #241B20, фон #F3EEEE, белый. Розового нет. Заливки, не обводки.
- Тексты на сайте короткие и по делу.
- Проверять на телефоне (390 px) и на компьютере.
