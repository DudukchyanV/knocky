# Knocky

Сервис онлайн-приглашений на свадьбу по ссылке: https://knocky.ru, кабинет https://app.knocky.ru.

**Подключаетесь к проекту? Начните с [HANDOFF.md](HANDOFF.md)** - там устройство, выкладка, правила владельца и текущий статус.

## Коротко о репозитории

- `index.html` - весь сайт, зашифрованный (AES-GCM). Репозиторий публичный, поэтому открытого исходника здесь нет.
- `src/knocky-src.enc` - зашифрованный архив рабочих исходников (`tools/seal_src.py`).
- `tools/` - шифрование сайта и исходников, сборка страницы гостя.
- `server/` - сервер и кабинет (Timeweb Cloud). Сервер раз в минуту забирает `main` и запускает `server/deploy.sh`.
- Пароли и токены в репозиторий не пишем.
